Adding Images in Prose

Floating image (right-aligned, text wraps around)

Use for portrait photos, flags, maps, and other images that sit alongside text. Default width is 220px.

<div class="ndx-prose-img">
  <img src="../../images/nedex/[FILENAME]" alt="[DESCRIPTION]" />
  <div class="ndx-prose-caption">[Caption text here]</div>
</div>

<p>Your prose text wraps around the image here...</p>

<!-- Add this after the section to clear the float -->
<div class="ndx-clearfix"></div>
Full-width image (sits between paragraphs)

Use for wide images like landscapes, building exteriors, or group photos.

<div class="ndx-prose-img-full">
  <img src="../../images/nedex/[FILENAME]" alt="[DESCRIPTION]" />
  <div class="ndx-prose-caption">[Caption text here]</div>
</div>
Annotation / Author Note

Use to add historical context, explain a divergence from OTL, or flag something for future expansion.

<div class="ndx-annotation">
  <div class="ndx-annotation-head">Historical Note</div>
  [Your annotation text here]
</div>
Stub / Section in Development

Use for sections that aren't written yet.

<div class="ndx-stub-notice">This section will be expanded to cover [TOPIC].</div>
