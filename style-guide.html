Rules & Ornaments
Horizontal rules carry meaning. Use the right one in the right place.
Thick rule — 3px solid --ink · Used: above lead section, above pull quote, top of nav card grid
Thin rule — 1px solid --ink · Used: below deck, below masthead topbar
Double rule — CSS border-top 3px + border-bottom 1px · Used: below section flags
Light rule — 1px rgba(25,21,16,0.15) · Used: column dividers, sidebar rows, table rows
Masthead rule ornament — thick + diamond + thin + diamond + thick · Used: under masthead title only
Party stripe
Always appears as the first element in the page, above everything. Height: 4px.
Left to right: Federalist (#C4601A) · Democrat (#1e7a48) · SPA (#a01e1e) · JCA (#b8900a) — each 25% of width

On August 24, 1814, British forces burned Washington City. In our history, it was rebuilt. In this timeline, it was not — and the two centuries that followed diverged profoundly from our own.

Chapter Page — Full Template Structure
Complete top-to-bottom structure for all chapter/article pages.
Page structure (top to bottom)
1 Party stripe (4px)
2 Masthead (topbar + Bebas Neue title + rule ornament + tagline)
3 Sticky nav bar (--ink bg, red top border)
4 Breadcrumb (Home › Primary Chapters › Chapter Name)
5 Prev/Next bar — top (border-bottom 1px --rule-light)
6 Section flag (red tag — "Chapter" + era/date kicker)
7 Hero identity block (portrait + headline + years + deck + meta strip)
8 Chapter body grid: 1fr main + 240px sidebar (gap 2.5rem)
↳ Main: Sub-chapter list → Article sections (heading + 2px rule + body + optional image/pull quote)
↳ Sidebar (sticky 3.5rem): Quick Reference → Key Events → Table of Contents → Related Links
9 Prev/Next bar — bottom (border-top 1px --rule-light)
10 Footer (--ink bg, 3px --red top border)
