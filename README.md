# Waymark — Washington Burns Timeline Interlink Site

A fan reference site for the **Washington Burns Timeline (WBT)**, an alternate history project with a point of divergence in August 1814.

This site mimics the **NANet** (North American Network) portion of the WBT's **Interlink** — a global network of regional networks, navigated via the `link://` protocol.

## How to use

Type any NANet address into the address bar on any page and press Enter (or →) to navigate. Recognised addresses will route to the correct node. Unknown addresses will flash an error.

## NANet address structure

`link://nan.[domain].[type].[country]`

**Type suffixes:** `.biz` (commercial) · `.pr` (press) · `.gov` (government) · `.edu` (educational) · `.org` (nonprofit)  
**Country codes:** `.usa` · `.can` · `.mex` · `.haw` · `.cal` · `.tex`  
**Supranational:** `.nau` (no country suffix needed)

Other networks: `ukn.` (UKNet/Britain) · `hw.` (HuaWang/China)

## Deploying to GitHub Pages

1. Push this repository to GitHub
2. Go to Settings → Pages
3. Set source to `main` branch, root `/`
4. Site will be live at `https://[username].github.io/[repo-name]/`
